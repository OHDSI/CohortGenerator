# CohortGenerator: Cohort Generation for the OMOP Common Data Model

Generate cohorts and subsets using an Observational Medical Outcomes
Partnership (OMOP) Common Data Model (CDM) Database. Cohorts are defined
using 'CIRCE' (<https://github.com/ohdsi/circe-be>) or SQL compatible
with 'SqlRender' (<https://github.com/OHDSI/SqlRender>).
