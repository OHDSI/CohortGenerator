# Abstract base class for subsets.

Abstract Base Class for subsets. Subsets should inherit from this and
implement their own requirements.

## See also

CohortSubsetOperator

DemographicSubsetOperator

LimitSubsetOperator

## Active bindings

- `name`:

  name of subset operation - should describe what the operation does
  e.g. "Males under the age of 18", "Exposed to Celecoxib"
